Projeto Event Cluster

O EventCluster é uma plataforma web para criação e gestão de eventos através de templates personalizados. O objetivo do projeto é facilitar a criação de sites de eventos, permitindo aos utilizadores escolher, personalizar e reutilizar modelos de forma simples. A aplicação foi desenvolvida com Laravel no backend. No frontend foram usadas tecnologias como HTML, CSS, Bootstrap e JavaScript, juntamente com bibliotecas como jQuery, DataTables e Font Awesome. A plataforma inclui funcionalidades como criação de formulários dinâmicos, onde foi usado FormBuilder, tornando a gestão de eventos mais prática.

Projeto académico em grupo.

Sistema para reservas online de um restaurante "Ristorante"

Este trabalho consiste numa plataforma de gestão de reservas para um restaurante, acompanhada por uma single page onde os utilizadores podem consultar informações e ementas do restaurante. O sistema inclui funcionalidades de registo e login, com diferentes perfis de utilizador (visitante, cliente, chefe de mesa e administrador), cada um com permissões específicas. A informação é armazenada numa base de dados SQL, de forma a reduzir redundância e otimizar a gestão de dados. O projeto foi desenvolvido com PHP, HTML, CSS e o framework Bootstrap.

Projeto académico em grupo.
